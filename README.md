# Nixus

A declarative, Incus-native NixOS hypervisor for homelabs.

Nixus is a fresh rewrite that succeeds [NixLab](https://github.com/OmarDardery/nixlab).
It is built from NixLab's `incus-native` rebuild without its history, without the
Docker applications VM, and without Arcane or Portainer.

> **Status: pre-release.** It is not yet qualified for installation. See
> [docs/migration-plan.md](docs/migration-plan.md).
