Apps

Deploy from Compose, Dockerfiles or Nix.

Upload a compose file, a Dockerfile or a Nix declaration. Nixus builds the images with incus-compose and deploys them. Updates are one click, with a snapshot and a rollback if the app doesn't come back healthy.

App page

Every app gets its own page.

Deployments, logs, environment variables and settings. Open it, restart it, stop it, or pass a USB or serial device through.

Secrets

Secrets with sops-nix.

Env vars are encrypted with one master key and only decrypted inside the app. Keep that key safe: export it as a recovery kit and store it off the server.

Backups

Full backups, plus your apps in git.

restic backs up your apps, their data, their secrets and this server's settings to Google Drive, S3 or a local disk. Your app declarations also sync to a git repo over SSH. To move to new hardware, install Nixus and restore with one password.

Sign-in

Your Linux account is your login.

Sign in to the console and Cockpit with the same user and password. Incus browser certificates are managed from the console too.

Changes

Host changes you can undo.

Every settings change is built and reviewed before it goes live. After activation you confirm from a fresh session; if you can't reach the server anymore, it rolls back by itself.

Tools

Just Cockpit and Incus.

No Portainer. Cockpit for the host terminal, services and logs; the Incus UI for containers and VMs. Both are one click from the console.

Why

Why the rewrite?
Nixus started as NixLab. A lot had to change, and porting it would have taken longer, been clunkier and left a lot of dead code.
Why the name?
It leans on Incus a lot, so I combined the names: nix + incus.
Why Go for the backend?
It's my favorite language. The console is plain JavaScript served by the same binary.
Who is it for?
Homelabbers who want a fully declarative server they can rebuild from a backup.

Install

On an existing x86_64 NixOS machine with virtualization enabled:

sudo nix --extra-experimental-features 'nix-command flakes' \
  run github:OmarDardery/Nixus#install

Then open the address it prints and sign in with your Linux account. Full install guide →
